# Six-phase implementation register

| Phase | Included in this ZIP | Further production work |
|---|---|---|
| V1 | Double-entry journal posting, contacts, documents, accounts, bank accounts, basic reports and dashboard | Detailed invoice lines, payments allocation, AR/AP aging, period close, reversals, approvals, full cashbook and export |
| V2 | Organizations, memberships, country/currency, tax rates, products/stock quantities, budgets | Full GST workflows/returns, HSN/SAC, place-of-supply, inventory valuation, warehouses, multi-branch permissions, forecasting |
| V3 | QuickBooks/Zoho/Tally provider adapter interfaces, connection and sync logs | OAuth, webhook, provider-specific mappings, live sync, conflict resolution and sandbox verification |
| V4 | Xero/Sage/FreshBooks adapter interfaces | Product/region-specific API implementation and certification |
| V5 | Audit events and extension points | AI provider, permissioned retrieval, source citations, cashflow forecasts, anomaly models, human approvals |
| V6 | Subscription plans, subscription state and tenant membership | Gateway integration, metering, billing documents, tax handling, regionalization, tenant isolation/security certification |
